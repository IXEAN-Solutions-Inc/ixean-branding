# Which logo file to use

You do not need a GitHub account. Click any file on GitHub, then click the download button (↓) at the top right of the file view.

To get everything at once, download [ixean-brand-kit.zip](https://github.com/IXEAN-Solutions-Inc/ixean-branding/releases/latest/download/ixean-brand-kit.zip). The release page also holds the large video files for editors.

## Pick the right colour

- Dark background (obsidian, black, dark photo area): use a file named `on-dark`.
- Light background (white, light grey): use a file named `on-light`.
- `color` files have a cyan tagline. `mono` files are one colour only.

## By tool

| You are working in | Static logo | Animated logo |
| --- | --- | --- |
| Canva | SVG from `assets/logo/svg/`, or PNG from `assets/logo/png/` | MP4 from `assets/motion/video/`. For a transparent overlay, use a GIF or WebP from `assets/motion/gif/` or `assets/motion/webp/`: Canva turns video transparency black. |
| PowerPoint | SVG (Microsoft 365 / 2019 and later), otherwise PNG | MP4 from `assets/motion/video/` |
| Google Slides | PNG (Slides does not accept SVG) | GIF from `assets/motion/gif/`, or upload the MP4 to Google Drive and insert it from there |
| Keynote | PDF from `assets/logo/print/` (`-rgb.pdf`) or PNG | MP4, or the ProRes MOV from the release for transparency |
| Premiere, After Effects, Final Cut, DaVinci | PNG or SVG | ProRes 4444 `.mov` from the release: it keeps transparency |
| CapCut | PNG | MP4. Transparent video is unreliable in CapCut; test before relying on it. |
| Email signature | PNG at 512 px, or the 320 px PNG in `assets/web/` | GIF (keep it short; some mail apps show only the first frame) |
| Word, Google Docs | PNG at 1024 px | — |

## Print vendors

Send the CMYK PDF from `assets/logo/print/` (`-cmyk.pdf`). If the vendor asks for EPS, send the `-cmyk.eps` file. If they ask for a Pantone colour, tell them none has been specified yet; do not let them guess one.

For print, the logo must be at least 50 mm wide with the tagline, or 25 mm without it. See [brand-guidelines.md](brand-guidelines.md) for clear space and the full list of rules.

## The animations

| Name | What it does | Length | Use it for |
| --- | --- | --- | --- |
| Ignition | Rings light up, circuit traces run to the centre, the name and tagline appear | 5 s | Opening a video, presentation, or event screen |
| Formation | Four rings fly in and lock into the vertical logo | 4.1 s | Opening, when a vertical layout fits better |
| Dispersal | The logo lifts apart and fades out | 3.4 s | Closing a video or presentation |
| Loaders: circuit, rotor, handshake, progress | Short seamless loops | 1.2–3.7 s | Loading screens in apps and websites |
